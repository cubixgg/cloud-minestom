# Security Policy

## Supported versions

Only the most recently published release of `cloud-minestom` / `cloud-minestom-bom` receives security
fixes — there's no LTS branch. See [`docs/compatibility.md`](./docs/compatibility.md) for what's
currently published and which Minestom/Cloud versions it was built against.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security vulnerability. Instead, use GitHub's
private vulnerability reporting: on this repo's **Security** tab, select **Report a vulnerability**.
That opens a private advisory visible only to maintainers.

Include, where you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal repro against `minestom-demo`'s command set is ideal)
- The `cloud-minestom` and Minestom versions involved

We'll acknowledge reports as promptly as we can and work with you on a fix and disclosure timeline
before anything is made public.
